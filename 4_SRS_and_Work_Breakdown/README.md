# SRS and Work Breakdown

This folder contains the Software Requirements Specification (SRS) and Work Breakdown documents for Problem Statement #49 – Webhook Ingestion & Retry Mechanism Hub.

## Contents

- `SRS.docx` – Software Requirements Specification document.
- `Work_Breakdown.docx` – Work Breakdown document describing the tasks and activities of the project.

## Project

**Project Name:** Webhook Ingestion & Retry Mechanism Hub

The project focuses on receiving third-party webhook events, recording webhook payloads, forwarding them to internal services, retrying failed deliveries, and handling undelivered events using a dead-letter queue.
